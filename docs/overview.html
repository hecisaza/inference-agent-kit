Spark Agent Kit

How an AI coding agent contributes to a local-inference serving stack without surprises: six stages, each with a gate, the scripts that make each stage repeatable, and the rules every agent reads first. Built on what Mia's AI Lab gives its contributors.

The process

Six stages, five gates

STAGE 0

Intake

  • Restate the task
  • sync.sh: latest main, open PRs, free patch number, collisions
gateOwner confirms scope and base; overlapping work named
STAGE 1

Build & host-test

  • Branch from the agreed base
  • Host tests before and after
  • canary.py: a test per fix
gateTests pass; every fix caught when reverted
STAGE 2

Review

  • review.sh: read-only bundle
  • A second agent reviews code and PR text together
gateNo open P1; each P2 fixed or listed
STAGE 3

Hardware

  • pairtest: build on an idle box, ship, run suites against a control, restore
owner's goDowntime window approved; report clean or understood
STAGE 4

Pull request

  • templates/PR.md filled from the report
  • Every claim re-read against the evidence
owner's goPush, fork, open: explicit, every time
STAGE 5

Follow-up

  • Rebase when the base PR merges
  • Replies to reviews go through the owner
gateMerged, or closed with a note
gate the agent checks itselfgate that needs the owner's explicit go

What runs underneath

Three layers

Rules AGENTS.md

never skipped
nothing public without the owner's go; the owner's name on the work; neutral about the lab; no secrets; live services belong to people
attribution
Mia's AI Lab's credit rules: names on the first screen, keep every existing credit, no "inspired by"
contribution
Mia's rules: announce only once merged, related PRs together, no colliding CHANGELOG edits

Tools scripts/

sync.sh
what upstream looks like right now
canary.py
switch each fix off, prove a test notices
review.sh
second-opinion review, answer extracted, hung reviewer stopped
pairtest
start, test, compare, report, restore — from lab.yaml

Evidence suites/ · evals/

smoke
arithmetic, greedy repeat, streaming
boundary
reply hashes at chunk ends and prefix-cache cases, sized to the engine's chunk
soak · cutin · fault
aborts and canaries over time; a short chat behind a long prompt; injected read faults
agent26
26 agent-style prompts with a grader and a blind side-by-side, for model swaps
